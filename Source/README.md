# Public source snapshot

This directory contains the public core source snapshot for CastleMiner Z World Builder v1.1.3.

`CMZ_World_Builder_v1.1.3_Public_Core_Source.zip` contains the same public core source set carried by the repository for earlier releases, updated to the v1.1.3 release state:

- `Shared/ArchiveDiscovery.cs`
- `WorldBuilder/WorldBuilderModels.cs`
- `WorldBuilder/WorldBuilderStandalone.cs`
- `WorldBuilder/WorldFormat.cs`

The private/release builder, build workspace, generated output, and builder ZIPs are intentionally not published in this repository.
